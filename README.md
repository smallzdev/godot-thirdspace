**2. Pixel art!**

I believe this is also our first time doing pixel art! For me (Victoria), I learned more than I expected on pixel art! I thought that it would be the same as drawing on paper, but surprisingly it's not. If you drew like you did on normal paper on a pixel art canvas, it would look super messy. So, I learned that you have to be mindful of your brushstrokes and colour.
