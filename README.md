# Third Spaces First Project!

This is our first submission to a Hack Club Program called [Third Space](https://thirdspace.hackclub.com/). We are both begginers, and have never made a game before. This game is made in the Godot engine.

Made with love by [Smallz](https://github.com/smallzdev) and [Vick-St3r](https://github.com/Vick-St3r)

## How do I play?
Instructions on how to play are coming soon.

## What our game is about

Our game is a platformer game. We're only begginers, so we're learning along the way.

Level 1: A simple grass level at the moment
Level 2: In construction

## Feature List
**Controls:**
- Jump (W, Space, or Up Arrow)
- Right (D, or Right Arrow)
- Left (A, or Left Arrow)
- Interact (E)

**Other Features**
- Checkpoints that change colour when activated
- Collectable coins
- 3 Life System
- Game Over Screen
- Going in the void that makes you respawn
- More!
